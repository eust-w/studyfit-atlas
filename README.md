# StudyFit Atlas

StudyFit Atlas is a MBTI-like browser game for exploring which country may fit a student's university study-abroad personality.

The result is for self-reflection and planning inspiration only. It is not admissions, immigration, or financial advice.

## What It Does

- Asks 8 personality and study-preference questions
- Scores answers against 6 destination profiles
- Recommends one country with a match percentage and explanation
- Shows score bars for all countries
- Runs fully in the browser with no backend or account

## Destinations

- Canada
- United Kingdom
- United States
- Germany
- Australia
- Netherlands

## Run Locally

```bash
npm install
npm run dev
```
